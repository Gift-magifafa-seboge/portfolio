# Gift Seboge — Portfolio

Personal site for Gift Sphelele Seboge, a Computer Science student at Tshwane University of Technology. It is aimed at Work-Integrated Learning placements.

## View it

Open `index.html` in a browser. There is no install and no build step.

## Files

- `index.html` — the page
- `style.css` — styles
- `fonts/inter-latin.woff2` — Inter, used for the page text
- `CV_Gift_Sphelele_Seboge.pdf` — CV linked from the page

`G_SEBOGE_WIL_CV.pdf` is an earlier CV kept in the repo. The page does not link to it.

Sections on the page: Home, About, Skills, Projects, Education, and Contact.
